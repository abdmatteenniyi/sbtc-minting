# SBTC Minting

This repository contains code and configuration for SBTC minting on the Stacks blockchain.

## Project Structure

- `settings/` — Contains configuration files for Mainnet and Testnet.
- `.cache/` — Used for caching; ignored in version control.
- `logs/` — Stores log files.
- `node_modules/` — Project dependencies (ignored in version control).
- `coverage/` — Test coverage reports.
- `costs-reports.json` — Cost analysis report.

## Getting Started

1. **Clone the repository:**
   ```sh
   git clone https://github.com/your-username/sbtc-minting.git
   cd sbtc-minting
   ```

2. **Install dependencies:**
   ```sh
   npm install
   ```

3. **Run the project:**
   ```sh
   npm start
   ```

## Scripts

- `npm start` — Start the application.
- `npm test` — Run unit tests.
- `npm run coverage` — Generate coverage report.
